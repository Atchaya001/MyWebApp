# CI/CD Pipeline Using Jenkins, Git, Maven and Apache Tomcat

## Project Overview
This project demonstrates an automated CI/CD workflow for a Maven web application using Jenkins, GitHub, and Apache Tomcat.

## Technologies Used
- Java
- Git and GitHub
- Jenkins
- Apache Maven
- Apache Tomcat
- Eclipse IDE

## Workflow
1. Develop the web application in Eclipse.
2. Push the source code to GitHub.
3. Jenkins retrieves the latest source code.
4. Maven builds the application and generates a WAR file.
5. Deploy the application to Tomcat.
6. Verify the updated website in the browser.

## Result
The Jenkins build completed successfully, and the updated web application was displayed in the browser.
